# 0001. Контейнери й ідентичність MQTT

Docker Compose керує PostgreSQL, окремою міграцією, Mosquitto, Worker, FastAPI, Nginx і бекапом. Nginx обслуговує наявний React SPA та HTTPS у одному контейнері. Збірку й тести винесено в окремі стадії образів.

Mosquitto використовує mTLS і нативну ACL замість незареєстрованого HTTP-хука. Це дає окремі ідентичності пристроїв і прибирає залежність старту брокера від API. Ціна рішення — оператор має підготувати довірений CA, вести CRL і видати унікальні сертифікати. Для ротації та автоматизованого provisioning потрібен наступний етап.

Той самий PostgreSQL використовується для нових записів. Міграції додають таблиці окремо від старого інвентарю й телеметрії, щоб зберегти історичні записи. Перенесення legacy-ідентичностей потребує окремого підтвердженого зіставлення.
